# Rohe App-Screenshots

Lege hier deine echten App-Screenshots im Hochformat ab:

```
1.png   Suchbildschirm
2.png   Suchergebnisse mit hervorgehobenen Treffern
3.png   Suchfilter (Bottom Sheet)
4.png   Einstellungen / Datenschutz
```

`../screenshots.html` setzt diese Bilder in den Telefonrahmen ein. Fehlt eine
Datei, zeigt der Rahmen einen Platzhalter. Quer-/Hochformat egal – das Bild
wird mit `object-fit: cover` in den Screen eingepasst.

Empfohlene Quelle: echte Geräte-Screenshots (z. B. 1080×2400). Export der
fertigen Store-Bilder siehe Anleitung oben in `screenshots.html`.
